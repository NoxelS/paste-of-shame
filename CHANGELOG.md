## [0.1.0] - 2026-01-28

### 🎉 Initial Release

First public release of Paste of Shame - your personal clipboard watchdog that catches LLM-generated boilerplate in real-time.

### ✨ Features

- **Real-time clipboard monitoring** - Watches your clipboard for AI-generated content as you copy
- **Smart detection engine** - Pattern-based detection system with configurable rules
- **macOS menu bar app** - Native menu bar integration with visual status indicators
- **Customizable severity levels** - Configure detection thresholds (low, medium, high, critical)
- **Language support** - Built-in rulesets for multiple programming languages and natural text
- **Notification system** - macOS notifications when problematic content is detected
- **Allowlist support** - Configure patterns to skip false positives
- **Performance optimized** - Minimal CPU usage with smart debouncing

### 🏗️ Technical Highlights

- **96% core functionality test coverage** - Comprehensive test suite with 56 tests
- **Type-safe codebase** - Full mypy type checking across 20 modules
- **Linted & formatted** - Ruff linting with strict code quality standards
